
# UDV Benefits Cafeteria
## Overview
The UDV Benefits Cafeteria is a web service designed to automate the process of selecting and requesting employee benefits. It simplifies communication between employees and HR by providing an intuitive platform for managing benefits.

***
## Features
* Employees can view and select available benefits.
* HR can manage benefits, approve requests, and track usage.
* Admins have full control over the system.
